## REQUIREMENTS
1. Use npm workspaces; no Turborepo/Nx.
2. Support Node.js >=22 and <27; CI reference runtime is Node.js 24 LTS.
3. Use TypeScript strict mode from one shared base config.
4. Use Biome for lint/format checks.
5. Use Vitest for deterministic unit/smoke tests.
6. apps/web is a minimal Next.js App Router shell with no product behavior.
7. apps/worker is a minimal Node.js TypeScript shell with no provider/trading behavior.
8. packages/domain must not import web, worker or provider implementations.
9. packages/contracts contains only generic TypeScript types/interfaces needed by the foundation; do not add a runtime schema library in M00.
10. packages/testkit contains deterministic test helpers only.
11. No test requires live network access or real credentials.
12. Root scripts expose lint, format:check, typecheck, test, build and validate.
13. npm run validate fails on any required check failure.
14. CI performs clean npm ci and the same required gates.
15. npm audit --audit-level=high must be captured as evidence.
16. Pin direct dependency versions exactly in package.json and commit the generated package-lock.json for transitive reproducibility.
17. Do not introduce runtime code not required to prove the harness.

## ARCHITECTURE RULES
- Preserve ports/adapters direction from frozen Architecture.
- Keep provider/business dependencies out of packages/domain.
- No deep cross-workspace relative imports.
- Prefer simple workspace scripts over new orchestration infrastructure.
- No environment-secret reads in library module import side effects.
- No hidden global mutable state in shared packages.
